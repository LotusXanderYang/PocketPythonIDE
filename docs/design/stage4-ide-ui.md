# 阶段 4：通用 IDE 界面设计

## 范围与保留项

本设计只用于 `ide` 宿主；Lab 保持原有工作台。保留 SAF 文件夹授权与冲突检测、文件树、多文件打开与保存、运行输出、Python 词法补全、Tab/Shift+Tab 缩进、括号与引号配对、冒号后换行缩进、字体大小、错误报告。语言能力仍由已验证的 API v1 包决定。

## 两套低保真布局

方案 A：任务条 + 工作区 + 文档 + 结果，适合横屏实体键盘。

```text
┌ P/IDE  文件  [工作区/文件] [搜索] [构建] [运行] [能力] [设置] ┐
├ 文件 | 项目搜索 | 语言包 | 任务 ┬ main.py ┬ helper.py ┬──┤
│ 工作区文件                       │ 工作区 / main.py          │
│ ▾ lesson                         │ 1  def main():             │
│   main.py                         │ 2      print('hello')       │
│   helper.py                       │                           │
│ 任务与最近结果                    ├ 输出 | 问题 | 构建记录 ─────┤
│                                  │ 任务状态与完整文本结果     │
└──────────────────────────────────┴ 行/列 · UTF-8 · 4 空格 ──┘
```

方案 B：单列任务切换，适合较窄窗口。

```text
┌ P/IDE [文件] [工作区] [搜索] [运行] [能力] [设置] ┐
├ 当前文件标签 ─────────────────────────────────────┤
│ 工作区 / main.py                                   │
│ 编辑器                                             │
│                                                    │
├ 输出 / 问题 / 构建记录，可折叠 ─────────────────────┤
└ 行/列 ─────────────────────────────────────────────┘
  文件按钮或 Ctrl+B 将文件面板切换到独立视图；Alt+1 返回编辑。
```

最终选择方案 A。宽屏同时保留文件上下文与编辑区，任务输出只在需要时展开；窄于 760 dp 时默认收起文件区，通过“文件”入口及 Ctrl+B 打开。与原界面相比，顶部直接呈现搜索、构建、运行及能力状态，左侧按开发任务命名，不再依靠无文字的工具图标。多文件标签独立于后退/前进历史。

## 关键状态

| 状态 | 显示与行为 |
| --- | --- |
| 空工作区 | 显示工作区名称与文件入口，编辑区为空；运行提示先打开文件。 |
| 无语言包 | 顶部显示“仅编辑”；文件可编辑保存，运行与构建给出语言包指引，记录在问题或构建区。 |
| 可检查 / 可运行 / 调试待接入 | 仅按已启用包的验证能力显示状态。“文件 → 检查当前文件”调用已验证的 `analyze`；构建只在 `build` 能力通过验证时调用包。即使语言包通过 `debug` 验证，宿主也显示“可运行·调试待接入”，直到阶段 8 有真实调试界面与实测结果。 |
| 构建失败 | 底部自动打开构建记录，保留失败文本；任务状态显示“构建失败”，问题区同步记录。 |
| 长任务 | 底部显示“运行中…”或“构建中…”，编辑器可继续编辑；任务入口和底部按钮提供取消。 |
| 背景授权失效 | 图片消失，编辑区回到纯色，提示重新选择；缓存文件删除。 |

## Token 与视觉规则

| Token | 值与用途 |
| --- | --- |
| 间距 | 4 dp 基数；常用内边距 8/12/16 dp，面板可触目标至少 40 dp 高。 |
| 分隔 | 1 dp 实线，深色 `#434946`，浅色 `#CFD6CC`；调整手柄 8 dp。 |
| 圆角 | 主要按钮和工作区入口 5 dp；编辑区、标签和面板仍保持直边。 |
| 正文字体 | Android 系统字体 12–14 sp；代码与结果使用等宽 15/13 sp；编辑字号沿用 10–32 sp 设置并跟随系统缩放。 |
| 深色 | 顶部 `#222726`、文件区 `#272C2A`、编辑区 `#1C2121`、正文 `#E8EBE4`。 |
| 浅色 | 顶部 `#EDF0EB`、文件区 `#F6F7F3`、编辑区 `#FCFCF9`、正文 `#1E2826`。 |
| 主体色 | 松绿 `#1F7E65`、陶土 `#AA5031`、靛蓝 `#4B5BAA`；用于主要动作与焦点。 |
| 图标语言 | 自有字母标识 `P / IDE`、简短文字动作和文件类型缩写；每个符号动作有文字或无障碍说明。 |
| 背景可读性 | 图片只在编辑器背层；深色至少 200/255、浅色至少 215/255 的底色遮罩。图片先采样至最长边约 1280 px，再缩至 960 px 宽，在后台模糊/调色并缓存。 |

实体键盘焦点顺序：顶部文件与工作区 → 搜索 → 构建/运行 → 能力与设置 → 左侧文件/任务 → 标签 → 编辑器 → 底部结果。Alt+1/2/3 可直接跳到编辑器/文件树/输出。补全弹窗用 ↑↓ 选择、Enter 插入、Ctrl+K 关闭，也可点底部关闭栏；能向应用发送 Ctrl+Space 或 Esc 的设备仍可用原快捷键。Tab 始终执行缩进。触屏可使用全部顶部与面板按钮，调整面板另有设置内的固定尺寸选项。

## 设置与数据

“设置”提供浅/深主题、三种主体色、编辑字号、SAF 图片选择、模糊/雾化/降饱和度/不透明度、低性能模式、重置背景、面板尺寸和快捷键。图片 URI 只用于本机，仅读取；处理缓存位于 IDE 私有 `cache/ide-wallpaper.png`。重置会清除 URI 和缓存；切换主题或效果会重新生成缓存。主题重建前先保存文件，保存失败时保持当前页面。

文件树轻点打开文件，触屏长按或鼠标右键打开文件操作菜单；其中“删除文件…”还需二次确认。顶部“文件 → 删除当前文件”可在无鼠标时使用。删除只针对文件，不递归删除文件夹；SAF 删除交由文档提供者执行，若拒绝则保留文件并显示原因。删除打开中的文件会移除相应标签和历史记录，编辑器切到另一个已打开文件或空状态。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新建 / 打开 / 保存 | Ctrl+N / Ctrl+O / Ctrl+S |
| 文件列表 / 标签切换 | Ctrl+P / Ctrl+Tab，反向 Ctrl+Shift+Tab |
| 当前文件 / 项目搜索 | Ctrl+F / Ctrl+Shift+F |
| 构建 / 运行 | Ctrl+Shift+B / Ctrl+Enter 或 F5 |
| 文件 / 输出面板 | Ctrl+B / Ctrl+J |
| 编辑器 / 文件树 / 输出焦点 | Alt+1 / Alt+2 / Alt+3 |
| 代码提示 | 输入时自动弹出；↑↓ 选择，Enter 插入，Ctrl+K 或点底部关闭；Ctrl+Space / Esc 仅在设备允许时可用 |
| 缩进 / 反缩进 | Tab / Shift+Tab |

Android 大屏和自适应布局参考：[Large screens UI](https://developer.android.com/guide/topics/large-screens/user-interface)、[Adaptive layouts](https://developer.android.com/design/ui/mobile/guides/layout-and-content/adapt-layout)。
