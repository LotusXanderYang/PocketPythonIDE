# 阶段 7 提示词：独立 Python · PyTorch Lab

请执行本阶段，并遵守 `docs/prompts/00-共同约束.md`。使用阶段 2 拆出的独立 Lab 应用，参考 `runtime.json`、运行时审计和 MAG-AN00 已有验证记录。不要把 Lab 做成通用 IDE 的一个语言包。

## 面向学生的最小流程

用户新建或打开训练项目 → 选择数据 → 修改少量 Python 代码／参数 → 启动 CPU 训练 → 查看进度与错误 → 停止或完成 → 导出模型与日志。界面只需简洁编辑器、任务状态、日志、文件与结果入口，不复制通用 IDE 的多面板布局。

## 实施任务

1. 保留现有 CPython、NumPy、CPU PyTorch 的版本与哈希证明。先复测导入、矩阵运算、自动求导和文件读写；不以先前版本的设备测试充当新 APK 测试。
2. 将训练从 Activity 中移出，验证进程隔离、用户取消、异常报告与任务结束后的资源释放。长任务需符合设备前后台限制；切后台、锁屏和系统回收行为要实测并在 UI 中解释。
3. 通过 SAF 明确导入数据与导出结果；项目内保存脚本、超参数、日志和检查点。检查点用临时文件完成写入后再原子替换或采用等效的防损坏流程；同名文件不能无提示覆盖。
4. 提供两个小型、离线、可复现的示例：一个矩阵／自动求导检查，一个极小训练任务。界面给出 CPU、内存、存储和耗电方面的现实预期；不暗示具备 GPU 训练。
5. 测量安装包、解包后存储、启动耗时、峰值内存和样例训练时间。之后才能试验裁减算子／依赖，并以同一测试集证明没有破坏需要的训练能力。
6. 记录包许可证、运行时构建方法、支持的 ABI／Android 版本及已测试设备。不能把任意桌面 wheel 标为兼容。

## 交付物与验收

- 独立 Lab APK、源码、使用说明与运行时清单；可与旧版和通用 IDE 并存安装。
- 实机完成小模型训练、保存与重新读取检查点、停止任务、异常恢复、数据导入和结果导出。
- 性能测量明确列出设备型号与测试条件；若目标设备无法完成训练，说明限制并收窄支持范围。
