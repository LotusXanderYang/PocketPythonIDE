## 改动

- 调试时左侧文件树切换为“运行和调试”侧栏，包含局部变量、全局变量、调用堆栈和断点；变量中的容器值可展开，点击堆栈或断点可跳回常规编辑器。调试控制位于编辑器标签下方；底部“调试控制台”显示输出。调试结束后左侧恢复文件树，控制台保留输出。窄屏设备将变量等信息放在底部调试视图中。
- “设置 → 导入编辑器字体”通过系统文件选择器接收 `.ttf` / `.otf`，限制 10 MiB，先在应用私有临时文件中校验，再替换私有字体文件；“恢复默认编辑器字体”可还原等宽字体。字体仅用于 IDE 编辑器与行号，原有工作区文件不变。
- “设置 → 代码高亮配色”可分别为浅色和深色主题配置基础文字、关键字、字符串、数字、注释和 C/C++ 预处理颜色；输入限定 `#RRGGBB`，保存后即时应用，支持恢复默认。未设置自定义方案时，Python 与 C/C++ 保留原有默认颜色。
- 左上角 `P / IDE` 文本替换为项目已有的原创 `ic_launcher` 图标。没有复制 VS Code 图标。
